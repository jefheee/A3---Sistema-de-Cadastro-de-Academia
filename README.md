# Sistema de Cadastro de Academia (A3)

Projeto acadêmico em TypeScript focado na lógica de negócio e testes unitários para gerenciamento de uma academia.

## Sobre o Projeto

O sistema implementa regras de negócio e serviços em memória para:
- **Membros:** Cadastro, consulta por ID/CPF, listagem e atualização de status.
- **Treinos:** Criação e vínculo de fichas de treino a membros existentes.
- **Pagamentos:** Registro e controle de pagamentos e histórico financeiro.

## Como Executar

### 1. Instalar dependências
```bash
npm install
```

### 2. Executar demonstração no console
```bash
npm start
```

### 3. Rodar os testes unitários
```bash
npm test
```
